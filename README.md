# Kaiser Permanente + Risant Health · Shared Collaboration Hub

Customer-branded GitHub Pages microsite for Kaiser Permanente + Risant Health.

Tells the story of `Kaiser-Permanente-Risant-Health-Value-Inversion.pptx` (the
"Enterprise Application Value Inversion" executive briefing) as an interactive
web experience, following the same click-driven tab/panel format as the prior
Centene and Risant Health "CRM Decision Canvas" hubs.

## Files

| File | Purpose |
|---|---|
| `index.html` | Landing page — published at the root of the repo. Branded with Microsoft + Kaiser Permanente + Risant Health logos. |
| `Kaiser-Risant-CRM-Decision-Canvas.html` | Passcode-gated Decision Canvas. Access code: **`KPRH0903`** |
| `gate_template.html` | Encryption gate template (used by `encrypt_resource.py`). |
| `encrypt_resource.py` | Helper to encrypt new resource HTML into a passcode-gated page. |
| `build_canvas.py` | Generator script for the raw Decision Canvas HTML — edit this, then re-run, rather than hand-editing the generated file. |
| `raw/decision-canvas.html` | Plaintext source of the Decision Canvas (generated by `build_canvas.py`). Do **NOT** publish — this is the unencrypted original. |
| `assets/` | Kaiser Permanente + Risant Health logo PNGs (also embedded as base64 inside the canvas HTML itself, so the published page has zero external asset dependencies) and `logos-b64.json` (cached base64 encodings used by the build script). |

## Content & format

- **Tabs (matching the CRM Decision Canvas format):** Problem &middot; Approach &middot; Control &middot; Payoff &middot; Plan.
- **Problem:** SaaSpocalypse + cost squeeze twin cards, the clickable Then/Now
  Value Inversion stack, the hyperscaler-tax comparison, and the compounding
  cost of a bolted-on data + AI layer.
- **Approach:** The Copilot "blind spot," fragmented-context healthcare stats,
  the clickable Work IQ / Foundry IQ / Fabric IQ three-things picker, and the
  Microsoft IQ platform architecture diagram.
- **Control:** A clickable 6-area governance grid (identity, policy,
  lifecycle, audit, telemetry, cost controls) for CIO/CTO conversations.
- **Payoff:** Kaiser Permanente's own $391.7M AI-BPS TAM (clickable vendor
  categories), the 10-year savings bar chart, the entity-split savings table
  (Kaiser Permanente / Geisinger / Cone Health), 6 healthcare proof points,
  and the compounding-return summary.
- **Plan:** The "scrutiny vs. the question that matters more" reframe, the
  closing statement, and three practical next steps plus full sourcing notes.
- **Branding:** Theme derives automatically from Kaiser Permanente (blue
  #006BA6) + Risant Health (gold #F6B350) brand colors, with purple/teal/green
  accents pulled from the source deck. Supports light/dark themes; hero logos
  swap to white versions automatically in dark mode.

## Access code

`KPRH0903` (Kaiser Permanente + Risant Health + build date MMDD). To rotate

## Publish to GitHub Pages

> Use your **personal** GitHub account `jgardn22` — enterprise accounts cannot
> publish Pages on the free tier.

1. Create a new repository at https://github.com/new
   - Name: e.g. `cx-kaiser-risant`
   - Visibility: **Public** (Pages on the free tier requires public)
   - Do **NOT** initialize with README/license (we already have files)

2. Upload these files to the repo root (Add file → Upload files):
   - `index.html`
   - `Kaiser-Risant-CRM-Decision-Canvas.html`
   - `assets/` (used by `index.html`'s header logos)
   - (Optional) `gate_template.html`, `encrypt_resource.py`, `build_canvas.py` if you want them versioned
   - Do **NOT** upload the `raw/` folder — that's the unencrypted source.

3. Commit to `main`.

4. Settings → Pages → Source = "Deploy from a branch", Branch = `main`,
   Folder = `/ (root)`. Save.

5. Wait 2–3 minutes. Refresh the Pages settings page. Your live URL will be:
   `https://jgardn22.github.io/cx-kaiser-risant/`

6. (Optional) Register an `aka.ms` short link pointing at that URL.

## Editing the canvas later

Do **not** hand-edit `raw/decision-canvas.html` or the encrypted
`Kaiser-Risant-CRM-Decision-Canvas.html` directly — edit `build_canvas.py`
(the CSS, HTML body, and JS data arrays are clearly separated in that file),
then re-run:

```
python build_canvas.py
python encrypt_resource.py --in raw/decision-canvas.html ^
    --out Kaiser-Risant-CRM-Decision-Canvas.html ^
    --code KPRH0903 ^
    --title "Kaiser Permanente + Risant Health Value Inversion Decision Canvas"
```

## Guardrails

- **No PHI, no member data, no sensitive internal-only Kaiser Permanente or
  Risant Health specifics beyond what's already in the source deck.** Pages
  sites are crawlable. The passcode is a courtesy layer, not real security.
- **Personal GitHub account only.**
- **Index.html at repo root is mandatory** — it's the trigger that makes `main`
  appear in the Pages branch dropdown.
- All TAM, savings, and cost figures are illustrative ranges based on Microsoft
  field experience and Kaiser Permanente-provided data as of 2026 — see the
  Plan tab's sourcing note and the source deck's backup slides before using any
  of these figures in an external or audited business case.
